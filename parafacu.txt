Consulta (versión ya corregida, con el filtro de borrado lógico completo)
SELECT u.nombre, u.apellido, p.fecha, p.estado, pr.nombre AS producto, dp.cantidad, dp.subtotal
FROM usuario u
JOIN pedido p ON p.usuario_id = u.id AND p.eliminado = FALSE
JOIN detalle_pedido dp ON dp.pedido_id = p.id AND dp.eliminado = FALSE
JOIN producto pr ON pr.id = dp.producto_id AND pr.eliminado = FALSE
WHERE u.id = 1
ORDER BY p.fecha DESC;

Datos que te pueden servir para armar el prompt
Hay 3 nodos de Nested Loop, anidados uno dentro de otro.
El más interno arranca con Index Scan using usuario_pkey (filtro id = 1) como tabla externa, y hace loop contra Bitmap Heap Scan on pedido como interna.
El segundo Nested Loop toma ese resultado como externa y lo cruza contra Index Scan on detalle_pedido (por la unique key pedido_id, producto_id).
El tercer Nested Loop (el más externo) toma ese resultado y lo cruza contra Index Scan using producto_pkey — notá el loops=22 en este último nodo, porque se ejecuta una vez por cada fila que llega desde adentro.
